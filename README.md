# Predicting-climate-linked-vector-borne-disease-outbreaks
# EDA
This study uses machine learning approaches to analyse the effects of climatic, environmental, sociodemographic, and geographic variables in order to forecast the occurrence of infectious disease outbreaks. Global disease transmission patterns have been drastically changed by climate change, necessitating the use of data-driven early warning systems. In order to address this, the study formulates outbreak prediction as a binary classification issue and combines data on global disease outbreaks with climatic variables.
Two publicly accessible datasets were used: a climate dataset from Kaggle that included variables like temperature, rainfall, CO2 emissions, sea level rise, forest cover, use of renewable energy, extreme weather events, and population, and a global epidemic and pandemic-prone disease outbreak dataset from Figshare. Preprocessing procedures such as country name standardisation, missing value imputation, feature scaling, one-hot encoding, class imbalance handling, and feature selection using the ANOVA F-test when applicable were performed after the datasets were combined by country and year.
Standard classification measures including accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrices were used to train and assess three machine learning models, Random Forest, XGBoost, and Logistic Regression. With boosted decision trees and early stopping, XGBoost produced the best overall performance, Random Forest used ensemble learning to capture nonlinear correlations, and Logistic Regression provided an interpretable baseline. The findings show how climatic factors and spatial context are crucial for predicting outbreaks and show how machine learning may help with early warning systems and public health planning that is climate resilient.
